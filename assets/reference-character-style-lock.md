# Character Style Lock — user-approved reference (2026-09-02)

Source reference: `assets/reference-character-style-20260902-no-shanghai.png` (Guilin, Nanjing and Beijing only; Shanghai excluded).

All cities from this point use this exact visual family. It supersedes the 2026-09-01 reference for new work:

- compact 4–4.5-head Q-style full body; rounded, gently simplified head and limbs;
- thin, slightly hand-drawn dark contour; no painterly marks, glossy highlights, photoreal anatomy, or 3D shading;
- small dot eyes, tiny nose and mouth, restrained peach cheek blush; warm friendly expression;
- matte, low-saturation flat color with only minimal garment folds;
- generous empty canvas and one fully readable body silhouette;
- preserve city-level `POSE_SIGNATURE` diversity: face direction, gesture, stance, footwear, silhouette and prop interaction vary; visual language does not.

Reference roles: this file controls only character rendering language and proportions. City research still controls contemporary, non-stereotyped outfit cues and pose locks.
